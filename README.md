# Pipely

A small CRM for managing leads through a pipeline: from **New** to **Won** or **Lost**.

> 🚧 Work in progress. Full documentation (setup, API, demo) will be added in a later phase.

## Tech stack

- **Backend:** Django 5 + Django REST Framework, PostgreSQL, JWT auth
- **Frontend:** React + Vite + TypeScript, Tailwind CSS
- **Infra:** Docker + docker-compose
